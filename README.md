# NEED Lab 홈페이지

중앙대학교 융합공학부 NEED Lab 연구실 홈페이지입니다.
빌드 과정 없이 파일을 그대로 올리면 동작하는 정적 사이트입니다.

## 내용을 고치려면

**`수정안내서.md` 를 읽어주세요.** 프로그래밍 지식 없이 고칠 수 있게 정리해 뒀습니다.

간단히 요약하면:
- 홈페이지에 보이는 내용은 전부 `content/` 폴더의 JSON 파일에 있습니다
- 사진은 `images/uploads/` 에 넣습니다
- HTML 파일은 건드릴 필요가 없습니다

## 로컬에서 확인하기

```
python3 -m http.server 8000
```
브라우저에서 http://localhost:8000 접속

## 화면이 깨져 보이면

zip을 **압축 해제한 뒤** 폴더 안의 `index.html` 을 여세요.
압축 파일 안에서 바로 열면 디자인·이미지가 따라오지 않습니다.

빠르게 보고만 싶다면 `NEEDLAB_미리보기.html` 을 여세요.
이 파일 하나로 전체 홈페이지가 동작합니다.

20분이면 끝납니다. 무료이고, 이후 웹 화면에서 바로 수정할 수 있습니다.

학교 웹서버나 다른 호스팅을 쓰려면 `수정안내서.md` 4장을 보세요.
